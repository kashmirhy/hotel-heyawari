# 山科・醍醐 歴史さんぽ（加茂川館 宿泊プラン用 観光ルートアプリ）

加茂川館（三条大橋西詰）を起点に、**「地下鉄・バス一日券」で乗れる交通機関だけ**を使って
山科・醍醐を巡るルートを自動作成するWebアプリです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これ1つで動作します） |
| `manifest.webmanifest` / `icon.svg` | スマホの「ホーム画面に追加」用 |
| `sw.js` | Webで公開した場合に、2回目以降オフラインでも開けるようにする仕組み |

## ゲストの使い方
1. QRコードからアクセス（またはダウンロードした `index.html` を開く）
2. 行きたいスポットをタップ（おすすめコースを選ぶと一括で選べます）
3. 「ルートを作る」→ 回る順番・乗る電車・時刻・費用が表示されます

## ルート計算のしくみ
- 起点・終点は加茂川館。最寄駅は地下鉄東西線「三条京阪」（徒歩約5分）
- 移動手段は **地下鉄東西線・京阪バス（一日券の適用範囲内）・徒歩**。一日券の範囲なので交通費は **0円** と表示し、参考として通常運賃も表示します
- 訪問順は、移動時間・開門/受付終了時刻・昼食の時間帯（11〜14時）を考慮して自動で決めます
- 徒歩15分以内なら歩き、それより遠く、地下鉄の方が早い場合は地下鉄を使います
- 御陵より先へ行く場合は「六地蔵行きに乗る（びわ湖浜大津行きは京阪線に入るので乗らない）」と案内します
- 上醍醐・方丈石など山道の先にあるスポットは、醍醐寺・法界寺からの山道の往復時間を含めて計算します

## 季節の見どころ・雨の日モード
- **季節**：スポット画面上部で春・夏・秋・冬を切り替えられます（初期値は今日の日付から自動判定）
  - 各スポットにその季節の見どころを表示し、「◯の見どころ」で絞り込めます
  - 桜・紅葉などで混みやすい季節のスポットは、なるべく朝早い時間に回る順番でルートを作り、昼以降になる場合は警告を出します
  - 冬期（12〜2月）は、閉門が早まるスポット（醍醐寺・毘沙門堂・法界寺・上醍醐など）の時間で計算します
- **雨の日モード**：スポットごとに「雨でも快適／傘があれば大丈夫／雨の日は不向き」の3段階を設定しています
  - オンにすると、屋内で楽しめるスポットが上に並び、「雨の日コース」がおすすめの先頭に出ます
  - ルートは歩く距離が短くなるよう地下鉄を優先し、山道など不向きな場所には注意を表示します
  - ルート画面にも季節・雨の日の切り替えがあり、作成後でもすぐに組み直せます

## スポットの追加・編集（ホテル担当者向け）
スポット管理は **パスコードを知っている担当者だけ** が開けます。ゲストの画面には入口のボタンを表示していません。

- **開き方**：「一日券・使い方」タブの一番下にある「加茂川館」の文字を **3秒以内に5回タップ**、または URL の末尾に `#admin` を付けて開く
- **初期パスコード**：`kamogawakan`（最初にログインしたら必ず変更してください。管理画面の一番下「管理者パスコードの変更」から変えられます）
- 5回続けて間違えると1分間ログインできなくなります。ブラウザを閉じると自動でログアウトします
- パスコードはハッシュ値で保存しており、書き出したHTMLに平文は含まれません
- 静的なHTMLのため、専門知識のある人が中身を解析すれば回避できる簡易的な保護です。ただし、管理画面での変更はその端末にしか保存されないため、ゲストの画面に影響することはありません

- **追加**：名前・位置（地図をタップ、またはGoogleマップの座標「34.xx, 135.xx」を貼り付け）・料金・滞在時間などを入力。最寄駅と徒歩時間は位置から自動で推定できます
- **編集・非表示**：最初から入っているスポットも内容の修正や非表示ができます
- **季節・雨の日の設定**：スポットごとに四季の見どころ、混雑しやすい季節、冬期の閉門時間、雨の日の快適さ・ひとことを入力できます
- **プラン設定**：プラン名、ゲストへのメッセージ、フロント電話番号（「困ったときは」欄に電話ボタンが出ます）

> ⚠ 管理画面での変更は **その端末にだけ** 保存されます。
> ゲストに反映するには **「配布用HTMLを書き出す」** を押し、ダウンロードされた `index.html` で公開中のファイルを置き換えてください。
> （変更内容がHTMLの中に埋め込まれます）

## 公開方法（QRコードで配布する場合）
例：GitHub Pages を使う場合
1. リポジトリの Settings → Pages で公開ブランチを指定
2. `https://<ユーザー名>.github.io/hotel-heyawari/kyoto-route/` でアクセスできます
3. スポット管理の「QRコードを作る」にそのURLを入れると、印刷用のQRコード画像を保存できます

ダウンロードして使う場合は `index.html` 1ファイルを渡すだけで動きます
（地図の表示とQRコード作成にはインターネット接続が必要です）。

## ご注意（データについて）
- 拝観料・営業時間・座標・徒歩時間は **目安** です。公開前に最新情報の確認をお願いします（特に食事処は例として入れたものです）
- 地下鉄の運賃は区間から計算した概算です
- 京阪バスは「地下鉄・バス一日券 適用範囲図」（2026/3/29版）をもとに、次の区間をルート計算に入れています。
  乗車時間・バス停からの徒歩時間は目安で、待ち時間は10分として計算しています（`index.html` の `BUS_LINKS` で調整できます）
  - 椥辻駅 ⇔ 大石神社（大石神社・岩屋寺）／醍醐駅 ⇔ 小栗栖（明智藪）／醍醐寺前・石田駅 ⇔ 一言寺／山科駅 ⇔ 北花山（元慶寺）
  - 法界寺・日野誕生院付近のバス停は範囲外のため、石田駅から徒歩で案内します
